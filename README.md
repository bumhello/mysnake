# 🐍 Змейка — Telegram Mini App

Классическая игра «Змейка» в виде Telegram Mini App. Без сборки, без сервера, без зависимостей — только HTML/CSS/JS.

## Возможности

- **Управление свайпами** — свайп вверх/вниз/влево/вправо (на десктопе — перетаскивание мышью)
- **2D-графика с эффектами** — свечение еды, частицы при поедании и смерти, тряска экрана, вспышка, пульсация, глаза у змейки, следящие за направлением
- **Динамическая сложность** — с каждой едой змейка ускоряется
- **Интеграция с Telegram WebApp** — haptic-отзывы, адаптация под тему, авто-раскрытие
- **Пауза** — при сворачивании вкладки игра ставится на паузу
- Бонус: если заполнить всё поле — победа 🏆

## Локальный запуск

Просто откройте `index.html` в браузере — игра работает без сервера.

```bash
open index.html
```

## Публикация (GitHub Pages)

1. Создайте репозиторий на GitHub и загрузите папку проекта.
2. **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Через несколько минут игра будет доступна по адресу:
   `https://<ваш-username>.github.io/<repo>/`

Альтернативы: **Vercel**, **Netlify** (перетащите папку на сайт) — работают так же.

> ⚠️ Telegram требует **HTTPS** — локальный файл подходит только для разработки.

## Создание бота и подключение Mini App

### 1. Создайте бота

1. Откройте в Telegram **@BotFather**.
2. Отправьте `/newbot`.
3. Задайте имя, например: `Snake Game Bot`.
4. Задите username, например: `my_snake_game_bot`.
5. BotFather пришлёт **токен** — сохраните его (нужен для шага 4, если захотите команду `/start`).

### 2. Зарегистрируйте Mini App

1. В BotFather: `/newapp` (или `/mybots → выберите бота → Bot Settings → Menu Button → Configure menu button`).
2. Выберите бота.
3. Укажите **URL вашей игры** (например, `https://user.github.io/repo/`).
4. Задайте короткое имя приложения — например `snake`.
5. BotFather пришлёт ссылку вида `https://t.me/<bot_username>/<short_name>` — по ней игра откроется в Telegram.

### 3. Кнопка меню (опционально)

`/mybots → выберите бота → Bot Settings → Menu Button → Set menu button` — укажите ссылку на игру, чтобы кнопка внизу чата открывала Mini App.

### 4. Команда /start с кнопкой (опционально, нужен токен)

Запустите бота на своём сервере (пример для Node.js):

```bash
npm init -y && npm i node-telegram-bot-api
```

```js
// bot.js
const TelegramBot = require("node-telegram-bot-api");
const bot = new TelegramBot("ВАШ_ТОКЕН", { polling: true });

bot.onText(/\/start/, (msg) => {
  bot.sendMessage(msg.chat.id, "Играй в змейку! 🐍", {
    reply_markup: {
      inline_keyboard: [[{ text: "▶️ Играть", web_app: { url: "https://user.github.io/repo/" } }]],
    },
  });
});
```

```bash
node bot.js
```

## Как играть

| Действие | Результат |
|---|---|
| Свайп влево/вправо/вверх/вниз | Поворот змейки |
| Тап / свайп на экране приветствия | Начать игру |
| Свайп после смерти | Рестарт |
| Свёрнутая вкладка | Автопауза |

Правила: собирайте жёлтую еду (+10 очков), не врезайтесь в стены и в себя. Скорость растёт с каждым съеденным плодом.
